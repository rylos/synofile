v0.1.20
- Connections to SMB and SFTP servers in the sidebar, under names you choose and can change. A bare host such as \\srv03 lists its shared folders. SMB takes domain, user and password; SFTP a password or SynoFile's own SSH key.
- Browse, preview, upload, download and rename on a server, and copy or move between the NAS and a server with the transfer dialog. A server path can be typed in the path bar.
- A more compact transfer dialog and folder picker.

v0.1.19
- The install and upgrade wizard has a step that says to run setup, with the command.
- CHANGES.txt: the changes of every version.

v0.1.18
- Space analysis leaves out read-only btrfs subvolumes (snapshots kept inside a shared folder, such as btrbk's).

v0.1.17
- Space analysis no longer enters anything mounted below the folder, as du -x: Active Backup for Business's FUSE view counted the same disk once per version.
- Space analysis colours each branch where the tree first divides.

v0.1.16
- Space analysis: right-click a folder or a shared folder to see what takes up the room, in rings around it (the idea of KDE's Filelight). Synology's own folders, snapshots and the recycle bin are left out.

v0.1.15
- Bug fix for error messages showing only "error 404": DSM's web server replaced them with its own error page.
- A favourite whose shared folder is missing (a USB drive unplugged) is greyed out and marked as not available.

v0.1.14
- An icon in DSM's taskbar while transfers run, are paused or wait for an answer, with the overall progress; a click shows each transfer. Settings > Transfers turns it off.
- Bug fix for the percentage of a transfer going back and forth near the end.

v0.1.13
- A more compact transfer dialog.

v0.1.12
- Settings > List > Show favourites.

v0.1.11
- The sidebar shows the volumes with their Storage Manager names.
- The volumes of the sidebar can be reordered by dragging or from their menu.

v0.1.10
- New settings: hidden files last, view and sort remembered for each folder, today's dates highlighted, where SynoFile opens and where new tabs open.

v0.1.9
- Archives open like folders: zip, 7z, rar, tar, tar.gz/bz2/xz/zst and iso. Copying items out extracts just those.
- Space on an archive shows what is inside.
- Transfers interrupted by a package restart are cleaned up and come back as interrupted, with Retry.
- Bug fix for extracting a .tar.gz giving only the inner .tar.
- Bug fix for a transfer into a folder you cannot write to showing "completed".
- 7-Zip gets an archive password on stdin, no longer on its command line.

v0.1.8
- Quick look: images fit the window, zoom with the wheel or + - 0 1, drag to pan.
- Properties for multiple selections.
- Bug fix for thumbnails and previews of large images showing only a piece of the picture.

v0.1.7
- HEIC/HEIF photos: thumbnails, previews and quick look, decoded in the browser.

v0.1.6
- Bug fix for tabs: as wide as their name, shrinking only when the tab bar is full.

v0.1.5
- Favourites can be reordered by dragging or from their menu; a folder dropped on the Favourites title becomes one.

v0.1.4
- Bug fix for the window flashing white when it opens.
- Bug fix for the page reloading itself on every opening after an upgrade.

v0.1.3

v0.1.2
- The settings show the version and the author.
- Bug fix for dialogs opening with their first button looking pressed.

v0.1.1
- Bug fix for the close button of a tab.
- The package builds from any checkout path.

v0.1.0
- First release: a file manager for the shared folders, in DSM's main menu, for administrators.
- Tabs, dual pane, list and grid with eza's icons and colours, fuzzy filter, search, quick look, uploads and downloads, archives, DSM's Recycle Bin, dark and light themes, nine languages.
- Transfers on the NAS as the DSM user who started them, with a speed chart, pause, speed limit, conflicts, btrfs reflinks and optional verification.
