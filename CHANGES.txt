v0.8.3
- SynoFile in DSM's Login Portal: Control Panel > Login Portal > Applications > SynoFile gives it an alias (https://nas/synofile/), HTTP/HTTPS ports of its own or a domain, with DSM's login page in front, as File Station has. The browser tab then says SynoFile, with its icon. Handy behind a reverse proxy.
- A button in the top bar opens SynoFile in a browser window of its own; Open in File Station still works from there while DSM's tab stays open.
- The icons of the top bar line up.

v0.8.2
- A text editor: Edit in the right-click menu of a text file (or F4, or the button in the info panel) opens it in an editor in the manner of the micro terminal editor: line numbers in a column of their own (left out of a mouse selection), the lines changed since the last save marked beside them, micro's syntax colours for about 150 file types, a status line, and micro's keys (Ctrl+S save, Ctrl+Q close, Ctrl+F find, Ctrl+L go to line, Ctrl+D duplicate line, Ctrl+K cut line, Alt+Up/Down move line; Ctrl+G lists them). A toolbar does the same with the mouse.
- Saving keeps the file's permissions, owner and Windows or Unix line endings, and asks before overwriting a file that changed since it was opened. Files up to 8 MB, UTF-8 text only; read-only when you may not write the file. Works on the NAS and on SMB and SFTP connections.

v0.8.1
- Folder icons: click a folder's icon in the info panel (or right-click it in the sidebar > Icon…) to give it an icon and a colour, for that folder only or for every folder with the same name. The icon follows the folder when it is renamed or moved in SynoFile.
- USB drives: an eject button beside USB, SD card and eSATA shared folders in the sidebar, and beside the favourites inside them; also in their right-click menus. It works like Eject in DSM's External Devices, and refuses while a transfer is using the drive.
- DSM's USB shared folders (usbshare1, usbshare1-2…) get a USB icon on their own.
- Bug fix for the info panel showing the first item of a folder just opened instead of the folder itself.
- A slightly taller speed chart in the transfer dialog.

v0.8.0
- SFTP connections can log in with a key of your own: paste it or load it from a file (OpenSSH, PEM or PuTTY; RSA, Ed25519, ECDSA). A passphrase is asked once; the key is kept encrypted, like the passwords.
- A clear message instead of "Could not read key" when the SynoFile key has not been created yet.

v0.1.20
- Connections to SMB and SFTP servers in the sidebar, under names you choose and can change. A bare host such as \\srv03 lists its shared folders. SMB takes domain, user and password; SFTP a password or SynoFile's own SSH key.
- Browse, preview, upload, download and rename on a server, and copy or move between the NAS and a server with the transfer dialog. A server path can be typed in the path bar.
- A more compact transfer dialog and folder picker.
