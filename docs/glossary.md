# Glossary

Shared by SynoFile and btrbk-nas, so the two packages say the same thing
the same way. Checked on 2026-10-29 against DSM 7.4.1's own translations
(/usr/syno/synoman/webman/texts/<lang>/strings and File Station's
ui/file_browser/texts): where DSM has the term, the table uses DSM's word.
Snapshot: DSM's texts translate it only twice (de Schnappschuss, fr
instantané, es instantánea, pt/pt-BR instantâneo, pl migawka, nl snapshot),
so the table keeps the product's own usage. DSM's own terms come first: where DSM names something, use
DSM's word in that language (as its interface shows it), not a synonym.
Brand and product names stay as they are: DSM, File Station, Synology,
btrfs, btrbk, Hyper Backup, reflink, zip, 7-Zip, SMB.

Tone: short, plain, the register of DSM's own interface. Address the user
the way DSM does in that language: German "Sie", French "vous", Spanish
"usted"-neutral impersonal forms, Dutch "u", Portuguese impersonal, Polish
impersonal forms. Buttons are infinitives or imperatives as DSM uses them.
